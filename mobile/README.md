# MiniShop · móvil

App React Native CLI (Android primero, iOS listo) que usa el dominio, el estado y los hooks de [`../core`](../core).

Desde esta carpeta: `npm ci`, `npm start` (Metro) y, en otra terminal, `npm run android`.

Requisitos, arquitectura, pruebas y APK: [README principal](../README.md). Problemas comunes: [troubleshooting](../docs/troubleshooting.md).
